# Dualità

Tavolo virtuale in italiano **compatibile con Daggerheart™** per giocare in gruppo (1 GM + 2-5 giocatori),
ognuno dal proprio telefono o computer.

App non ufficiale realizzata da fan. Usa materiale del Daggerheart System Reference Document 1.0,
© Critical Role, LLC, secondo la Darrington Press Community Gaming License
(https://www.darringtonpress.com/license). Vedi la pagina "Crediti e licenza" nell'app.

- App online: https://cesta73.github.io/dualita/
- Stack: Vite + React + TypeScript + Tailwind, Supabase (database, tempo reale, accesso anonimo), test con Vitest.
- Regole del progetto: `CLAUDE.md`. Avanzamento: `docs/AVANZAMENTO.md`.
